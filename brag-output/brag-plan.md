# Brag Plan: Sophos

## What is this app?
Sophos is a Windows-native port of Prime Intellect's open-source Prime Agent (upstream credited) as a polished desktop app — Tauri v2 shell, Node bridge sidecar, React frontend — 1,118 tests passing, for developers on Windows 10/11.

## The angle
The port is the product. The video performs the honest-port story on screen: the real app views (Chat, Sessions graph, Agents fleet, Skills) arrive one by one like native windows, then the receipts land — 1,118 tests, upstream credit given by name. The hook is the tagline itself: "Own your intelligence." No parody, no hype — a clean product film.

## Hook (first 2-3 seconds)
Full-screen settled lockup: small "SOPHOS · WINDOWS-NATIVE" marker, giant "Own your intelligence.", sub "Prime Agent, ported to Windows as a polished desktop app." The tagline IS the hook.

## Key moments (the middle)
- The app views recreated: 4 sharp-cornered panels (Chat · Sessions graph · Agents fleet · Skills) arriving one by one on the beat grid, then holding as a set — exactly the app's real surfaces.
- The receipts: "1,118 tests passing" landing on the strong cue, with "upstream credit: PrimeIntellect-ai/prime-agent" and "Tauri v2 · Node bridge · React".
- The honesty line, verbatim in spirit: "A Windows port — all agent-runtime credit to the Prime Intellect team."

## Outro / punchline
"Sophos — Own your intelligence." + "Windows 10/11 · signed installer · MIT-licensed." Lands on the final strong cue; one soft bell payoff.

## User flow worth showing
Entry → key action → result: open the desktop app → drive work through Chat + Sessions + Agents views → ship from a signed Windows installer. Centerpiece scenes show the real views (the product doing its thing), framed by the port story.
